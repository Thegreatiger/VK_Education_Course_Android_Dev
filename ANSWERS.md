# Выводы по загрузке рейтингов

Приложение загружает рейтинги для 41 приложения.

1. **Последовательный метод (`loadRatingsSequentially`):**
   Время выполнения: ~62 секунд (41 эл * 1.5 с/эл = 61.5 с).
   Рейтинги загружаются строго один за другим.

2. **Параллельный метод (`loadRatingsInParallel`):**
   Время выполнения: ~1.5 секунды.
   Благодаря использованию `async` + `awaitAll`, все запросы(элементы) запускаются одновременно.

**Вывод**: Параллельный способ загрузки корутин на порядок эффективнее, когда несколько независимых сетевых запросов не зависят друг от друга.
